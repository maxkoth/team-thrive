# Team Thrive — Interactive Prototype (Phase 2)

A click-through demo of the new Phase 2 features, built from the real RonasIT designs.
It runs entirely in the browser — no install, no internet, no login.

## What's inside
- **Guided tours** — one per new feature: Deep-Link Invitation, Multi-Team Event Invites,
  Responsible Parent, Club Account, Import Players, and Welcome & Onboarding.
- **Explore mode** — every one of the 119 screens, searchable.
- Sample names and data are illustrative; the screens are the actual Phase 2 designs.

## Open it locally (fastest)
Double-click `index.html`. It opens in your browser. That's it.

## Present it
1. Open a feature card.
2. Click the phone — or press the **→** arrow key — to advance. **←** goes back.
3. The caption under the phone explains each step. Dots let you jump around.
4. "Next feature" moves to the following story.

## Share a public link (so Aliza can open it anywhere)
1. Go to **https://app.netlify.com/drop**
2. Drag the whole `team-thrive-demo` folder onto the page.
3. Netlify gives you a public URL in a few seconds. Share that.
(Any static host works too: Vercel, GitHub Pages, etc.)

## Record a video
Open a tour full-screen, start your screen recorder (macOS: QuickTime → New Screen
Recording, or Cmd+Shift+5), and step through with the arrow key. Narrate as you go.

## Notes for the team
- This is a **prototype of the designs**, not the live React Native app. It won't diverge
  from what coaches see because it *is* the Figma screens.
- To update: drop new PNGs into `/screens` and add them to a tour in `index.html`
  (the `TOURS` array near the bottom).
